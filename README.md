# PDF Report Generator

A Python toolkit for generating professional PDF reports from structured data, with clean structure, type hints, and a command-line interface.

Overview

PDF Report Generator is a modular Python application that renders data into polished PDF documents. It demonstrates professional engineering practices: a documented entry point, structured logging, and a testable design.

Features

Clean, modular Python code with full type annotations

Structured logging using the standard library

Simple, extensible command-line interface

Ready for unit testing

Requirements

Python 3.9 or later

Installation

```bash
git clone https://github.com/Shiv-0707/pdf-report-generator.git
cd pdf-report-generator
python -m venv .venv
source .venv/bin/activate # Windows: .venv\Scripts\activate
```

Usage

```bash
python main.py
```

Project Structure

```
pdf-report-generator/
└── main.py
```
